# Fallback untuk agent tanpa discovery skill

Untuk permintaan membuat lab Cisco Packet Tracer, baca `SKILL.md` di folder ini dan ikuti alur generator Python. Gunakan `README.md` untuk format input. Jalankan perintah dari workspace pengguna dengan path script absolut bila perlu. Jangan mengubah file sumber pengguna; output memakai direktori baru. Laporkan terpisah hasil validasi struktur, round-trip codec, pembukaan di aplikasi, dan penerapan konfigurasi.

Instruksi ini hanya berlaku untuk pekerjaan paket Cisco Packet Tracer ini.
